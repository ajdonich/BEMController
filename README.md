## iPhone app to control handheld, battery powered PEMF device

This repo houses a SwiftUI iPhone application for controlling a handheld PEMF prototype (Pulsed Electromagnetic Field therapy). A more detailed overview of the project can be found here: [PEMF-PROTOTYPE](https://github.com/ajdonich/pemf-prototype). This app was tested with an STMicro [Nucleo-68 Dev Board](https://www.st.com/resource/en/user_manual/um2435-bluetooth-low-energy-and-802154-nucleo-pack-based-on-stm32wb-series-microcontrollers-stmicroelectronics.pdf). It communicates with the device via BLE, but is otherwise identical to the WIFI enabled version here: [EMController](https://github.com/ajdonich/EMController).
